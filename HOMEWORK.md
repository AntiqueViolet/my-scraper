# Домашнее задание

## Уровень 1. Больше данных (обязательно)

Сейчас скрипт собирает у каждого персонажа только `name` и `status`.

- Добавь в словарь внутри цикла ещё поля из API: `species`, `gender`, а также `origin`.
- Убедись, что новые колонки появились и в `data/ur_faces.json`, и в `data/res.xlsx`.

## Уровень 2. Чиним и расширяем статистику (обязательно)

В API есть три статуса: `Alive`, `Dead` и `unknown`. Сейчас в конце печатаются только «Живых» и «Мёртвых», а `unknown` теряется.

- Добавь вывод количества персонажей со статусом `unknown`.
- Посчитай отдельную статистику по видам (`species`): сколько персонажей каждого вида.
- Положи `species_stats` в итоговый `result` рядом со `stats`, чтобы оно попало в JSON.

## Уровень 3. Docker (обязательно)

Проект уже собирается в контейнер. Прогони полный цикл и запиши команды, которыми пользовался.

- Собери образ: `docker build -t my-scraper .`
- Запусти через compose, чтобы результат сохранился на хост: `docker compose up --build`
- Убедись, что папка `data/` на твоём компьютере заполнилась (том проброшен в `docker-compose.yml`).

## Уровень 4. GitHub (обязательно — это и есть «сдача»)

- Проверь, что `data/` не попадает в репозиторий: добавь строку `data/` в `.dockerignore` и заведи `.gitignore` с той же строкой (результаты парсинга в гит не заливаем).
- Сделай отдельные коммиты по смыслу по КАЖДОЙ задаче, например:
  - `feat: собираем больше полей о персонажах`
  - `feat: статистика по видам и статусу unknown`
  - `refactor: выносим URL и задержку в переменные, обрабатываем ошибки`
- Запушь ветку на GitHub (шпаргалка — в `github.txt`).
