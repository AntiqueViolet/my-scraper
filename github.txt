1. git init - инициализация гитхаба в рабочей директории

2. git remote add origin <ссылка на репозиторий гитхаба> - добавление проекта

3. git add . - добавить все измененные файлы в коммит

4. git commit -m "Описание коммита" - закоммитить изменения в проект

5. git push - отправить изменения в гитхаб
