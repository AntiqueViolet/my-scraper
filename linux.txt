1. mkdir <имя ДИРЕКТОРИИ> - создать директорию
   rmdir <имя ДИРЕКТОРИИ> - удалить директорию

2. cd <имя ДИРЕКТОРИИ> - перейти в директорию (на WINDOWS условно открыть папку)

3. ll - увидеть все файлы в текущей директории

4. scp -r ./server-prod root@45.156.20.238:/root/12-07/

scp -r . <имя пользователя>@<адрес сервера>:/имя директории/ - из текущей всей папки на сервер
scp -r ./<имя папки> <имя пользователя>@<адрес сервера>:/имя директории/ - из подпапки проекта в директорию на сервер (Деплойная папка)

5. cat <имя ФАЙЛА> - посмотреть в терминале содержимое файла

6. nano <имя ФАЙЛА> - изменить содержимое файла

ctrl+o - записать данные (сохранить)
ctrl+x - выход

7. clear - очистка терминала
